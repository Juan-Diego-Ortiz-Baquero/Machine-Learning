Definición y Conceptos Clave

¿Qué es la Regresión Lineal?

La regresión lineal es un método estadístico y de Machine Learning que modela la relación entre una variable dependiente (objetivo) y una o más variables independientes (características), asumiendo que esta relación es lineal.

Caso de Estudio: En nuestro ejemplo práctico, utilizamos regresión lineal para predecir la nota final de un estudiante basándose en las horas de estudio y horas de sueño.

Ecuación Matemática

y = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ + ε
Donde:
• y = Variable dependiente (nota final)
• β₀ = Intercepto
• β₁, β₂...βₙ = Coeficientes
• x₁, x₂...xₙ = Variables independientes
• ε = Error residual

Supuestos Fundamentales

Para que la regresión lineal funcione correctamente, se deben cumplir ciertos supuestos estadísticos:

1. Linealidad

La relación entre las variables independientes y la dependiente debe ser lineal. Se verifica mediante gráficos de dispersión.

2. Independencia

Las observaciones y los errores deben ser independientes entre sí. Importante en series temporales.

3. Homoscedasticidad

La varianza de los errores debe ser constante para todos los valores de las variables independientes.

4. Normalidad del Error

Los errores se distribuyen normalmente con media cero. Se verifica con test de Shapiro-Wilk.
