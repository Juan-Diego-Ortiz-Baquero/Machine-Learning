Predicción de abandono escolar

Este modelo utiliza regresión logística para predecir si un estudiante abandonará sus estudios. Las variables consideradas son: Horas de estudio semanales, Número de fallos previos, Nota final, Apoyo escolar, Apoyo familiar, Acceso a internet y Deseo de educación superior.

Explicación del dataset

La variable objetivo es Dropped_Out: 1 = Sí, 0 = No.

Predicción de abandono universitario

Variables originales: Promedio académico, Asistencia a clases, Horas de estudio, Carrera (categórica).
Objetivo: ¿Abandona el estudiante? (Sí/No).
Autores del trabajo: Laura Bernal, Santiago Valenzuela, Julieth Alvarado, Juan Ortiz.

Nota: En el dataset original de Kaggle no existe la variable 'Promedio académico' tal cual, por lo que se reemplazó por 'Final_Grade' (nota final) como aproximación.

Fuente de datos:
Abdullah0a. (2023). Student Dropout Analysis and Prediction Dataset [Conjunto de datos]. Kaggle. https://www.kaggle.com/datasets/abdullah0a/student-dropout-analysis-and-prediction-dataset?resource=download
