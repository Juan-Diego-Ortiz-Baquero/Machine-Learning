Variables Predictoras
Variable Objetivo: Dropped_Out

0 = No abandona 1 = Sí abandona

El modelo utiliza variables académicas (horas de estudio, nota final, ausencias) y socioeconómicas (apoyo familiar, acceso a internet) para realizar las predicciones.

Variables Académicas
  • • Horas de estudio semanales
  • • Número de ausencias
  • • Nota final del curso
Variables Socioeconómicas
  • • Apoyo escolar disponible
  • • Apoyo familiar recibido
  • • Acceso a internet en casa
  • • Aspiraciones de educación superior

Fuente de datos: Abdullah0a. (2023). Student Dropout Analysis and Prediction Dataset [Conjunto de datos]. Kaggle.

Nota: Dataset adaptado para fines educativos. La variable 'Final_Grade' se utiliza como aproximación del promedio académico original.
